# Development Vault

This directory serves as a standalone Obsidian vault for testing and developing the **Obsidian Duet Agent** plugin.

## Usage
1. Open Obsidian desktop or mobile.
2. Select **Open folder as vault** and choose this `dev-vault` folder.
3. Build the plugin with `npm run build:plugin`.
4. Ensure **Obsidian Duet Agent** is enabled in Obsidian Settings $\rightarrow$ Community Plugins.
