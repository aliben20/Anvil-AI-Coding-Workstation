## 2. Upstream & Environmental Constraints (Non-Defects)

### Item 1: Native Linux PTY on Windows Host
- **Severity**: Informational / Platform Limitation
- **Status**: Working by design. Native Linux `/dev/pts` pseudo-terminals require a Linux kernel (or WSL). On Windows hosts, OBSIDIAN automatically routes terminal execution to Windows PowerShell and Command Prompt (`child_process.spawn`) with full ANSI color output and directory tracking. Linux-specific PTY tests in `tests/workstation.test.ts` are cleanly skipped with `# Linux environment required`.

### Item 2: Free Tier API Quota Limits (Google Gemini API)
- **Severity**: External Resource
- **Status**: Working by design. Free-tier Google Gemini API keys are limited by Google to 20 requests per day for preview models. When this limit is reached, OBSIDIAN provides transparent error reporting (`HTTP 429: RESOURCE_EXHAUSTED`) with time-to-retry indicators, and allows the user to switch seamlessly to offline local AI or configure an alternative cloud provider (OpenAI, Anthropic, DeepSeek, Ollama).
