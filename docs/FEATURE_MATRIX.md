# Feature Matrix & Reuse Decisions (`docs/FEATURE_MATRIX.md`)

| Capability | Mobile-Harness (`com.jarves.mh`) | PocketStrike-AI (`server.py`) | Anvil AI Coding Workstation Decision |
|---|---|---|---|
| **Android UI** | Native Kotlin + Jetpack Compose (`PocketDevApp.kt`), Material 3, dark theme, localized strings; monolithic 7.3k-line file | Vanilla HTML/CSS/JS web UI served by Flask inside Termux | **Rebuild cleanly**: Modular Kotlin + Jetpack Compose in `android-workstation/` + live responsive Graphite Workstation UI (`src/`) with 5 primary destinations (`Chat`, `Projects`, `Agents`, `Terminal`, `Settings`) |
| **AI Provider Integration** | `ProviderApiClient.kt` supporting OpenRouter, Anthropic, OpenAI Chat/Responses, DeepSeek, Kimi, OpenCode Zen, NVIDIA NIM, Custom API | Basic OpenAI/Ollama HTTP calls in `server.py` | **Adapt Mobile-Harness design + Server-Side Gemini**: Multi-provider architecture (`AIProvider`, `ModelCatalog`) supporting Built-in Gemini 3.8 Flash, OpenRouter, OpenAI, Anthropic, DeepSeek, and OpenCode Zen with real connection tests and model discovery |
| **Authentication & Secrets** | `ApiKeyVault.kt` using Android Keystore AES-GCM (`AES/GCM/NoPadding`) + PKCE OAuth helpers | Plaintext JSON config on disk | **Reuse & Harden Mobile-Harness**: Android Keystore AES-GCM in Kotlin (`ApiKeyVault.kt`) + Node `crypto` AES-256-GCM vault on server with full secret redaction (`sk-...xxxx`) |
| **Agent Orchestration** | Delegates to external CLI binaries (`claude-code`, `deepseek-harness`, `antigravity`) inside PRoot | Built-in Python ReAct loop (`get_ai_response_with_tools`) with function calling | **Combine & Harden**: Native bounded ReAct `AgentEngine` with explicit step plan, iteration/tool limits, permission checks (`PermissionManager`), real tool execution (`ToolExecutor`), and change verification |
| **Workspace Editing** | `BoundedFileReads.kt` + `WorkspaceCheckpoints.kt` for safe file reads, diffs, and revert snapshots | Basic `read_file_content` / `write_file_content` without diffing or checkpoints | **Adapt Mobile-Harness + Expand**: Full project browser, templates, file tree, code editor, unified diff viewer, and checkpoint revert system |
| **Terminal / Runtime** | PRoot Ubuntu 20.04 (`NativeSpawnProcess`, `RuntimeExecutionService`) for ARM64 Android | `StatefulShell` subprocess wrapper preserving `cwd` | **Combine**: Native Android `TerminalSession` + PRoot runtime bridge in `android-workstation/`, and real `/bin/bash` `StatefulShell` process execution with streaming output, exit codes, and `SIGINT` cancellation in live host |
| **Memory & Retrieval** | Minimal conversation history in `AppPreferences` | `memory.md`, `user.md`, `conversations.json` in `workspace/agent/` | **Adapt PocketStrike Concept Safely**: Structured `MemoryStore` with global notes, project-scoped context, conversation search, keyword retrieval, and explicit user-controlled retention |
| **MCP Integration** | Handled indirectly only if external CLI agent supports it | Native JSON-RPC 2.0 over Streamable HTTP & SSE (`query_streamable_http_tools`, `StdioMcpConnection`) | **Adapt PocketStrike HTTP/SSE MCP**: Clean `McpClient` adapter with server registry, JSON-RPC 2.0 `tools/list` discovery, schema validation, timeout, and permission gating |
| **Local AI (GGUF)** | Not natively integrated (relies on cloud/gateway APIs) | Delegates to external Ollama HTTP server | **Implement Honest Local Model Manager**: Real GGUF binary header parser (`GGUF` magic bytes, version, tensor count, architecture metadata, RAM requirement vs. device memory check) + JNI `llama.cpp` adapter boundary |
| **APK Build Pipeline** | `AndroidBuildSupport.kt` + `AndroidProjectTemplateGenerator.kt` + `AndroidAppInstaller.kt` | Only `analyze_apk_manifest` | **Reuse & Verify Mobile-Harness**: Real project type detection, toolchain diagnostics (`java`, `javac`, `gradle`, `ANDROID_HOME`), real build command runner, real `.apk` ZIP/Manifest binary verifier, and Android `PackageInstaller` flow |
